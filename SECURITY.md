# Security policy

Report backend and manifest vulnerabilities privately using the repository's
GitHub Security tab when private reporting is enabled. If unavailable, request
a private reporting channel in an issue without disclosing exploit details or
personal data. Private reporting should be enabled before release.

Include the trigger/backend commit, Spotty version, native build details,
attacker-controlled input and a reproduction using synthetic data. Never attach
API keys, real clipboard history or confidential documents.

See [Privacy and security](PRIVACY_AND_SECURITY.md) and
[Spotty's security policy](https://github.com/Aras1907/Spotty/blob/main/SECURITY.md).
